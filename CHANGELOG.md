# Changelog

All notable user-facing changes are recorded here.

## [0.2.0-beta.1] - 2026-07-12

### Added

- Versioned beta release process for Windows x64.
- Portable ZIP and Inno Setup installer build targets.
- GitHub Actions CI and tag-based prerelease workflow.
- Help > About dialog and versioned main window title.
- App icon source graphic and Windows `.ico` file.

### Notes

- This beta is unsigned. Windows may show a SmartScreen warning until future
  releases are code-signed.
- Updates are manual: download the newer portable ZIP or installer from GitHub
  Releases.
